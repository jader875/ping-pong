# ping-pong
Пинг-понг - это очень веселая игра на двоих человек, где вы играете в пинг-понг вдвоем, там вы отбиваете мячик, и если вы его не отбили, и он упал, то вы проигрываете, это очень веселая игра на двоих. Игра разработана разработчиком из Сызрани по имени Jader. реализована на языке программирования Python, один игрок управляет ракеткой с помощью клавиш W и S, а второй с помощью стрелки вверх и стрелки вниз.
